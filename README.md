# Gourav Maurya — Portfolio v1

Apple-inspired portfolio for recruiters and clients, with selected AI/full-stack projects, experience, skills, contact links, and the supplied résumé.

## Preview

No build or dependency installation is required.

```sh
python -m http.server 4186 --bind 127.0.0.1 --directory dist
```

Active files: `dist/index.html`, `dist/v1.css`, `dist/v1.js`, and `dist/assets/`. Earlier styles and scripts remain archived in the repository but are not loaded by v1.

The redesign uses responsive project showcases, native project disclosures, restrained entrance motion, reduced-motion support, visible keyboard focus, and an accessible copy-email status.
